# CSCI-521-Data-Cleaning

## Setup

> [!TIP]
> Use python virtual environment to avoid conflict with global packages
> Initialize the venv `python -m venv .venv`
> You will need to source the venv to run the project
> Windows: `.venv\Scripts\activate`
> Linux/MacOs: `source .venv/bin/activate`

Install packages `pip install -r requirements.txt`

## Running

If using virtual environment, ensure the environment has been sourced.

- Windows: `.venv\Scripts\activate`
- Linux/MacOs: `source .venv/bin/activate`
